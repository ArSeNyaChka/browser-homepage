# browser-homepage

Моя домашняя страница для браузера — работает как **New Tab Page** в Chrome и Firefox.

## Возможности

- **Быстрый доступ** — иконки сайтов слева и справа.
- **Умный поиск** — подсказки сайтов (по алиасам + русским раскладкам) и строки поиска DuckDuckGo.
- **Панель алиасов** — добавление и удаление алиасов без правки `sites.json`, импорт и экспорт в JSON.
- **Темы** — «Стандартная» (по умолчанию) и «Терминал» (моноширинный шрифт, зелёная палитра).
- **Адаптивность** — корректно отображается на мобильных устройствах и планшетах.

## Установка (Chrome / Edge)

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** (справа вверху).
3. Нажмите **Загрузить распакованное расширение** → выберите эту папку.
4. Откройте новую вкладку — домашняя страница готова.

## Установка (Firefox)

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение** → укажите `manifest.json`.

## Алиасы сайтов

`sites.json` — базовый список вида `{"алиас": {"name": "Название", "url": "example.com"}}`.
Он остаётся нетронутым: свои алиасы и скрытые базовые хранятся отдельным слоем в
`chrome.storage.local` (или `localStorage`, если страница открыта не как расширение),
поэтому «Сбросить» всегда возвращает к содержимому файла.

Панель открывается кнопкой ⚙ в правом нижнем углу. В поле алиасов значения
разделяются пробелом или запятой — можно сразу завести несколько, включая русские
раскладки (`n нот notion`).

Формат импорта/экспорта совпадает с `sites.json`.

## Темы

Тема сохраняется под ключом `homepage.theme`.

```js
homepageTheme.set('terminal');   // «Терминал»
homepageTheme.set('standart');   // «Стандартная»
```

## Тесты

Проверки логики алиасов гоняются на чистом Node, без браузера:

```bash
node tests/sites.test.mjs
```

## Структура проекта

```
├── css/
│   ├── style.css           ← токены палитры, раскладка, адаптив
│   └── terminal.css        ← переопределение токенов для темы «Терминал»
├── icons/                  ← иконки сайтов
├── js/
│   ├── utils.js            ← escapeHtml
│   ├── sites.js            ← sites.json + пользовательские правки, хранилище
│   ├── searchline.js       ← поисковая строка, подсказки, навигация
│   ├── aliases-panel.js    ← панель управления алиасами
│   └── ui.js               ← тема, фокус
├── tests/
│   └── sites.test.mjs      ← проверки js/sites.js на Node с моками fetch/localStorage
├── sites.json              ← базовые алиасы
├── index.html
└── manifest.json
```
